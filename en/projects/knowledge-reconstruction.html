Overview

Why this project exists

Classroom material is often fragmented across audio, slides, notes and temporary explanations. The project explores a repeatable workflow that turns raw learning material into structured outputs while keeping the user able to review intermediate results.

Problem

Problems addressed

01

Unstructured input

Audio transcripts and notes are difficult to review when they remain as one long block of text.

02

Disconnected concepts

Important terms and relationships are easy to miss without a structured knowledge view.

03

Weak review loop

Learners need summaries and questions that can be checked against the original material.

04

Privacy risk

Classroom data and model configuration require explicit local and public-release boundaries.

Core Features

Core workflow

01

Input processing

Accepts classroom text and supports a workflow for speech-to-text input.

02

Knowledge extraction

Identifies concepts, topics and candidate relationships for structured review.

03

Knowledge graph

Displays relationships in a visual graph rather than only a flat list.

04

Structured summary

Produces review material organized by topic and hierarchy.

05

Question generation

Creates practice questions from processed classroom content.

06

Local persistence

Uses SQLite for lightweight local storage and repeatable testing.

07

Offline safety mode

Allows safe validation without sending sensitive classroom data to external services.

08

Regression tests

Tests core service behavior, safety checks and public-release contracts.

Limitations and Safety

Boundaries

The project is a local learning prototype. Generated summaries and questions still require human review. Public evidence excludes API configuration, identity information, original classroom records, local paths and other sensitive material.
