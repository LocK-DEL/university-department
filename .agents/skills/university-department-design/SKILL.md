# University Department Design Skill

## Mission

Transform university-department into a premium, modern, trustworthy educational platform.

The goal is not a generic AI-generated landing page. The interface should feel like a world-class university technology product: intelligent, calm, academic, precise, and memorable.

## Design Philosophy

Priorities:

1. Brand credibility
2. Information clarity
3. Visual hierarchy
4. Premium typography
5. Responsive excellence
6. Subtle but meaningful interaction

Avoid:

- Generic purple/blue AI gradients
- Excessive glassmorphism
- Repeated three-card layouts
- Huge empty hero sections with meaningless slogans
- Decorative animations without purpose
- Fake statistics, testimonials, awards, or university claims

## Visual Direction

Preferred aesthetic:

- Modern academic technology
- Premium SaaS clarity
- Research institution atmosphere
- Editorial layouts
- Strong typography
- Carefully controlled motion

References in spirit:

- Apple product pages
- MIT/Stanford research websites
- High-end education platforms
- Premium developer documentation

## Implementation Rules

Before changing UI:

1. Inspect existing architecture.
2. Preserve routes, data, SEO, and functionality.
3. Read PRODUCT.md and DESIGN.md if available.
4. Make changes incrementally.

Every page must define:

- Purpose
- Primary user action
- Information hierarchy
- Visual rhythm
- Mobile behavior

## Typography

Typography should create hierarchy:

- Large display headings for identity
- Comfortable reading widths
- Clear academic tone
- Avoid excessive font weights

## Layout

Use:

- Strong grid systems
- Intentional whitespace
- Asymmetric layouts where appropriate
- Meaningful section transitions

Avoid:

- Every section looking identical
- Excessive rounded cards
- Nested containers

## Motion

Animations should explain:

- Navigation
- State changes
- Content relationships
- Product identity

Do not add animation only for decoration.

## Quality Checklist

Before completion:

- Desktop verified
- Mobile verified
- Accessibility checked
- Typography checked
- Contrast checked
- Loading states considered
- Empty states considered
- Production build passes

## Collaboration With Other Skills

Impeccable owns:

- UX quality
- Accessibility
- Responsive behavior
- Design system consistency
- Final polish

Taste/design exploration skills own:

- Creative direction
- Visual experimentation
- Avoiding generic layouts

When conflicts happen:

1. Product truth wins.
2. User experience wins.
3. Accessibility wins.
4. DESIGN.md wins.
5. Creative exploration adapts.
