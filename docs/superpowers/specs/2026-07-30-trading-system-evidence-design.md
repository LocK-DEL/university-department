# 交易系统真实运行截图接入设计

日期：2026-07-30

## 目标

在 `projects/trading-system.html` 中加入两张真实本地运行截图，增强“多周期行情分析与风控报告金融交易系统”的可验证性。

## 展示结构

新增“Interface Evidence / 真实运行界面”章节，位于系统结构/技术栈之后、当前验证状态之前。

1. 主图：实时监控与风控总览
   - 展示行情列表、Execution Guard、AI Radar 与 Position Review。
   - 说明其为本地运行界面，不构成投资建议。
2. 辅助图：命令行运行与计划输入
   - 展示 Binance Futures 连接、Telegram 告警状态、交易计划输入与执行保护。
   - 必须遮挡 Telegram chat_id、token 前缀及本地绝对路径。

## 隐私与真实性边界

- 不公开 API Key、API Secret、Telegram token、chat_id、账户信息或本地绝对路径。
- 不修改 36 项测试、本地 CLI 状态、无下单功能等既有事实。
- 不宣称稳定盈利、自动赚钱、完整生产部署或投资建议。
- 图片使用本地 WebP 资源，不依赖第三方图床或 CDN。

## 交互与响应式

- 桌面端主图全宽，辅助图置于下方。
- 手机端自然纵向排列，无横向滚动。
- 图片可点击打开原尺寸文件；使用明确 alt 文本和图注。
- 不新增 JavaScript 依赖。

## 验收

- 两张 WebP 文件均可解码。
- 第二张图中敏感字段不可辨认。
- 页面包含新增章节、图片、图注和风险边界文案。
- 360px 与 1440px 下无水平溢出。
- CNAME 与项目 URL 不变。
